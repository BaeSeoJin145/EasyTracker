# Kinematic Lab

정적 브라우저 앱으로, 업로드한 영상을 서버에 보내지 않고 프레임 간 움직임을 검출해 궤적과 기본 운동량을 CSV로 내보냅니다.

## 실행

`index.html`을 최신 브라우저에서 열면 됩니다. 정적 호스팅에 세 파일(`index.html`, `styles.css`, `app.js`)을 올려도 동작합니다. 외부 라이브러리나 빌드 과정은 필요하지 않습니다.

## 분석 방식

1. 영상에서 최대 600px 폭으로 축소한 프레임을 최대 420개까지 일정 간격으로 읽습니다.
2. 영상 전 구간에서 고른 최대 7개 프레임의 픽셀별 중앙값을 배경 모델로 구성합니다.
3. 현재 프레임과 배경의 평균 RGB 절대 차이가 민감도 임계값보다 큰 픽셀을 전경으로 표시하고, 8방향 연결 성분을 객체 후보로 사용합니다.
4. 면적과 형상 필터를 거친 검출 중심을 최근 궤적에 거리 기반으로 연결하고, 프레임 간 위치를 속도와 가속도로 근사합니다.

화면상의 기준 길이 입력은 원본 영상 픽셀 기준입니다. 두 보정값을 모두 입력하면 실제 길이 단위(cm)로, 비워 두면 원본 해상도 픽셀 단위로 표시합니다. CSV에는 샘플 시각, 중심 좌표, 검출 박스 크기, 속도가 포함됩니다.

이 구현은 객체 종류를 인식하지 않으며 학습된 CNN 추적기를 재현하는 것도 아닙니다. 배경 차분 기반 무학습 베이스라인입니다. 고정 카메라와 선명한 대비가 필요하고, 가림·접촉·큰 카메라 이동·복잡한 조명 변화에서는 ID가 바뀌거나 궤적이 누락될 수 있습니다. 가속도는 화면의 y축 방향을 양수로 한 포물선 최소제곱 근사값이며, 원근 보정·카메라 기울기 보정·실험 불확도 추정은 포함하지 않습니다.
